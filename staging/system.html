System

A dielectric body holds a capacitance:

C = ε₀ εr A / d

A hand at the surface adds to it. What is added is orders of magnitude smaller than what is already there:

ΔC / C₀ < 10⁻²

And the baseline is not fixed. It moves with temperature and humidity:

C₀ = C₀(t)

Detection occurs when ΔC crosses a threshold. The threshold is set per stone, because density, porosity and retained water put it somewhere different every time. Each unit is calibrated alone. There is no general value.

What follows is one encoded instruction, sent once, at a wavelength long enough that walls are not a factor:

λ = c / f
